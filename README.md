# Portfolio de Chamsdine Koudri

Site vitrine en HTML, CSS et un peu de JavaScript, inspiré du jeu Wakfu.

## Structure

- `index.html` : écran titre
- `menu.html` : choix de la rubrique
- `personnage.html`, `competences.html`, `quetes.html`, `contact.html` : une page par rubrique
- `css/style.css` : le style de tout le site
- `js/script.js` : le formulaire de contact
- `assets/` : les images et le CV en PDF

## Publication

Le site est publié avec GitHub Pages depuis la branche `main` (dossier racine) :
chaque push sur `main` met le site en ligne automatiquement.
